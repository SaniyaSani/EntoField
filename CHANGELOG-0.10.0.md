# EntoField 0.10.0 - Grouped Label Studio

- Adds one Label Studio for collection labels, determination labels, or both.
- Keeps independent dimensions, font sizes, auto-enlargement, line spacing, and
  vertical alignment for the two label types.
- Groups labels by type on clean rows or keeps matching record labels paired.
- Adds shared guillotine-grid, spaced double-guide, and no-guide cutting modes.
- Shows an exact A4 preview generated by the same PDF engine as the download.
- Brings the same workflow to a single collecting event and a whole field trip.
- Preserves the Field Ink interface, original EntoField branding, offline PWA,
  and Photo Library or Camera picker from 0.9.2.
