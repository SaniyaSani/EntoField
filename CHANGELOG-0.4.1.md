# EntoField 0.4.1

## Installation reminder

- Added a compact installation call-to-action below **New collecting event**.
- Reused the existing installation flow from **Settings** instead of creating a second installer.
- Added iPhone/iPad and Chrome/Edge installation hints directly in the call-to-action.
- The reminder is hidden when EntoField is opened as an installed app.
- Settings now shows an installed status when the app is running in standalone mode.

No field-record, specimen, export, or storage logic was changed.
