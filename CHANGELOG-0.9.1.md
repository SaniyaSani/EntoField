# EntoField 0.9.1 - Field Ink

## Visual identity

- Added the hand-drawn EntoField fly dragging a specimen locality label.
- Reworked the interface as a readable field notebook with paper surfaces,
  ink-like outlines, label stamps, hand-drawn map details and restrained green
  and pink accents.
- Added matching browser and installable PWA icons.
- Kept data fields, coordinates and longer text in clear interface type.

## Usability and offline support

- Corrected singular count labels such as `1 event` and `1 individual`.
- Added the new logo assets to the offline application shell.
- Bumped the service-worker cache so installed copies receive the redesign.

## Compatibility

- Swiss WGS84, LV95 and LV03 label output is unchanged.
- Collection and determination label workflows remain separate.
- No data migration is required.
