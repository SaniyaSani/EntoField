# EntoField 0.8.0 - Field Trip Label Sheets

## Combined collection labels

- Added a **Collection labels** action to every field trip.
- All collecting events are selected by default and can be included or excluded
  individually.
- Quick mode provides an independent copy count for every selected event.
- Recorded-material mode creates one label per specimen or lot across all
  selected events.
- Labels from consecutive events are packed continuously into the same A4 PDF,
  without reserving or wasting a separate page for each event.

## Compatibility

- Single-event collection labels and separate determination labels continue to
  work as before.
- Existing local EntoField data remains compatible; no schema migration is
  required for this release.
